# 🐉 Targaryen Shop 🐉

Welcome to **Targaryen Shop**, a high-performance, futuristic Android application crafted by **flash** ⚡. This project showcases the power of modern Android development using the **Nexus Design System**.

---

## 🚀 Features

- **⚡ Cyber-Nexus UI**: A dark-themed, neon-infused interface featuring custom components like `NexusCard`, `NexusBadge`, and `NexusLoader`.
- **📡 Real-time Data**: Integrated with JSONPlaceholder API to fetch and display posts, users, and photos.
- **🔄 Fluid Transitions**: Smooth state transitions and loading animations for a seamless user experience.
- **🏗️ Reactive Architecture**: Built with MVVM and Kotlin Coroutines for a lag-free performance.

---

## 📱 Screens

### 👥 Users
Explore the list of users with a sleek avatar system and detailed contact information.
- **List View**: Overview of all users with quick-glance badges for company and city.
- **Detail View**: Full profile information including contact details, location, and company catchphrases.

### 📝 Posts
A clean interface for reading through the latest updates and content fetched directly from the cloud.

### 🖼️ Photos Grid
A visually rich, responsive grid gallery featuring high-quality images and full-screen detail views.
- **Responsive Grid**: Uses `LazyVerticalGrid` for an optimized viewing experience.
- **Detail View**: Immersive photo viewing with metadata integration.

| Category | Tools |

## 🎨 Design Language (Nexus)

The project uses a custom theme located in `ui.theme`:
- **Neon Purple** & **Neon Cyan**: Core accent colors.
- **Plasma Glow**: Secondary highlight for a futuristic feel.
- **Dynamic Shapes**: Circular clips and rounded borders for a modern aesthetic.
